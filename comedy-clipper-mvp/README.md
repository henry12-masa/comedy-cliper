# ComedyClipper MVP

お笑いチャンネル向けの自動切り抜きツールMVPです。

## 機能

- 漫才・コント・トーク動画の読み込み
- 笑い声・拍手っぽい音を検出
- 急なツッコミ・大声を検出
- 「間」のあとに盛り上がった場面を検出
- 候補のプレビュー
- MP4切り抜き書き出し
- タイトル案・テロップ案の自動生成

## 使い方

1. `index.html` をブラウザで開く
2. 動画を選択
3. 検出モードを選ぶ
4. 「笑える切り抜き候補を検出」を押す
5. 候補をプレビュー
6. MP4を書き出す

## 検出モード

### 笑い・拍手重視

笑い声、拍手、会場の盛り上がりを優先します。

### トークの山場重視

急な声量変化、ツッコミ、間のあとの盛り上がりを優先します。

### ショート向け強め

短尺動画で使いやすい、派手な音量変化を優先します。

## ローカルサーバーで起動する場合

ブラウザで直接開いてFFmpegが動かない場合は、以下で起動してください。

```bash
python -m http.server 8000
```

その後、以下を開きます。

```text
http://localhost:8000
```
